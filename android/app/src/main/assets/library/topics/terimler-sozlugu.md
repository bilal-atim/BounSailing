Gezi eğitimlerinde en sık geçen terimler. Tam liste ve ayrıntılar için bkz. [[src:temel-denizcilik-terimleri|Temel Denizcilik Terimleri]] kaynağı.

## Marina ve liman

| Terim | Anlamı |
|---|---|
| **Marina** | Teknelerin bağlandığı liman |
| **Palamar** | Tekneyi rıhtıma bağlayan halat; marinada bu işi yapan görevliye de palamar denir |
| **Pasarella** | Tekneden rıhtıma geçmek için kullanılan yürüme köprüsü |
| **Tonoz** | Kıçtan bağlanmada kullanılan, denizin dibinden alınan bağlama halatı |
| **Kakıç** | Tonozu sudan almak için kullanılan uzun kancalı çubuk |
| **Açmaz** | Manevrada teknenin sıkışabileceği, çıkışı olmayan pozisyon |

Bkz. [[yanasma-ayrilma]]

## Tekne bölümleri

| Terim | Anlamı |
|---|---|
| **Baş (pruva) / Kıç (pupa)** | Teknenin ön / arka kısmı |
| **Bordo / Alabanda** | Teknenin dış yan yüzeyi / onun iç kısmı |
| **Küpeşte / Güverte** | Kenarda yürünen yer / öndeki açık üst yüzey |
| **Havuzluk** | Kıçta oturulan, dümenin bulunduğu alan |
| **Portuç** | Halat ve malzemelerin konulduğu depo |
| **Omuzluk** | Baş ve kıç arasındaki köşe bölgeler |
| **Lumbar ağzı** | Kabine girilen kapı |
| **Sintine** | Suyun biriktiği en alt nokta |
| **Aynalık** | Teknenin kıç dış yüzeyi |
| **Bimini** | Havuzluğun üstünü kapatan güneşlik tente |

Bkz. [[teknenin-tanitilmasi]]

## Seyirler ve manevralar

| Terim | Anlamı |
|---|---|
| **Orsa / Apaz / Pupa** | Rüzgârı önden / yandan / arkadan alan seyirler |
| **Volta seyri** | Art arda tramola atarak rüzgârüstüne çıkmak |
| **Tramola / Kavança** | Rüzgârüstünden / rüzgâraltından kontra değiştirmek |
| **Ayı bacağı** | Ana yelken ve ön yelkeni ters taraflarda kullanma trimi |
| **İğnecikten almak** | Rüzgârı tam kıçtan (180°) almak |
| **Köre düşmek** | Rüzgâra fazla dar açıyla girip hız kesmek (bocalamak) |
| **İstemsiz kavança** | Kontrolsüz, bumbanın aniden savrulduğu kavança |

Bkz. [[tramola]], [[kavanca]], [[ayi-bacagi]]

## Pratik kurallar

- **Dalgada:** Dalgaya çıkarken orsala, inerken kafayı aç; dalgayı baş omuzluktan al
- **Tüyler:** Dış tüyler çalışmıyorsa orsala, iç tüyler çalışmıyorsa kafayı aç
- **Zodi = Dingi:** İkisi de tekneye eşlik eden küçük şişme bot
